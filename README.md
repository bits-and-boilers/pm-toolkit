# PM Toolkit

Practical, reusable templates for running technology programs: the unglamorous documents that keep platforms running, migrations on track, and retirements clean.

These come from 26 years of owning enterprise platforms and SaaS applications. Every template is written from scratch and is generic: no company-specific content.

## Templates

| Template | Use it when |
|---|---|
| [Platform Retirement Plan](templates/platform-retirement-plan.md) | You need to shut down a system without losing data, breaking integrations, or surprising users |

## How to use

Copy a template, delete the guidance text in *italics*, and fill in the rest. Each one is plain Markdown, so it works in GitHub, Confluence, SharePoint, Notion, or a Word doc.
